# CN Client Tracker

A simple web app to track clients, project status, and notes for a freelance web agency.

Built because I was managing leads and projects across texts and spreadsheets and needed one place to see everything.

**Live:** https://web-production-d9ae8.up.railway.app

## Stack

- Python / Flask
- SQLite
- Deployed on Railway

## Run locally

```bash
git clone https://github.com/jack-nolan-dev/cn-client-tracker
cd cn-client-tracker
pip install -r requirements.txt
python app.py
```

App runs at `http://localhost:5000`.
